# CyberShield — Cybersecurity Awareness Hub

A responsive static website that introduces common online threats and practical cybersecurity habits. Built with HTML, CSS, and vanilla JavaScript.

## Features

- Responsive layout for desktop, tablet, and mobile
- Cyber threat information cards
- Practical security habit checklist
- Client-side password characteristics demo
- Five-question cybersecurity awareness quiz with feedback and score
- Accessible navigation labels, visible keyboard focus, skip link, and reduced-motion support
- No backend, build tools, dependencies, or personal-data collection

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Alternatively, open the folder in VS Code and use a local preview extension.

## Publish with GitHub Pages

1. Create a public repository on GitHub, for example `cybershield`.
2. Upload all four files to the repository root and commit the changes.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then click **Save**.
6. Wait for the deployment to finish. The website will normally be available at:
   `https://YOUR-USERNAME.github.io/cybershield/`

Replace `YOUR-USERNAME` with your GitHub username. If the repository has a different name, the URL will use that name.

## Important note about the password demo

The password checker runs locally in your browser and does not submit the input to a server. For safety, enter a fictional example only. Its scoring is a simple educational heuristic, not a full password-strength audit. Do not use the demo to store, share, or test a real password.

## Educational disclaimer

This site provides general cybersecurity awareness information. It is not a substitute for professional incident response, and the quiz is not a formal assessment.
