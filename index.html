KNOW THE RISKS

Threats to watch for

Recognizing common attack patterns helps you pause, verify, and respond safely.

✉

01 / MESSAGES

Phishing

Fake emails, texts, or websites designed to trick you into sharing passwords, payment details, or personal information.

Look for urgency, odd links, and unexpected attachments.
⌁

02 / MALICIOUS SOFTWARE

Malware

Software that can steal information, spy on activity, damage files, or give an attacker access to a device.

Install trusted software and keep protection enabled.
▣

03 / DATA LOCKOUT

Ransomware

A type of malware that encrypts files or blocks access and demands payment to restore access.

Keep separate backups and report suspicious activity.
♟

04 / HUMAN TARGETING

Social engineering

Manipulation that persuades people to reveal information, transfer money, or bypass normal security checks.

Confirm unusual requests through a trusted channel.

MAKE SECURITY A HABIT

Five habits that make a real difference.

Security doesn't have to be complicated. Start with these repeatable actions and build from there.

Try the security tools →
01

Use unique passwords

Use long, unique passwords for each account. A reputable password manager can help.

✓
02

Turn on multi-factor authentication

Add a second verification step, especially for email, banking, and social accounts.

✓
03

Pause before clicking

Check the sender and domain. Visit important sites using a saved bookmark or typed address.

✓
04

Update your devices

Install operating-system, browser, and app updates to receive important security fixes.

✓
05

Back up important files

Keep backups and periodically check that you can restore them when needed.
